# Guia Git — PDProject2025

---

## Formato de Commits 
- [tipo]: [descrição curta]
### Tipos que vamos usar
#### Principais
- feat: nova funcionalidade
- fix: correção de erro
- merge: dev para main
#### Outros
- docs: mudanças em documentação
- chore: manutenção/definições

### Exemplos
feat: adicionar cliente TCP
fix: corrigir fechamento do socket
docs: atualizar README
chore: criar .gitignore inicial
